## Fixed-1/6 source

**DERIVED** Let $B=\left.\beta_h\right|_4$, $H=B-2\epsilon h, a=1-6\xi$, and $a_d=1-6\xi _d=\epsilon /(3-2\epsilon )$. There is a simple source conversion when the conformally continued curvature source has homogeneous bare subtraction $a_B=a_d+Z_M a_C$. To justify that form, Weyl-flatten the massless matter action. Its local dimensionless bare couplings acquire their engineering Weyl powers, and these can be realized by local renormalized couplings along the d-dimensional RG vector. With one metric insertion, their gradients contribute to the mass source only $via d_I \Box g^I$ in Jack–Osborn (8.18), since the terms quadratic in gradients have no linear part. Remove the kinetic equation-of-motion term by using the pointwise bare field normalization. At fixed phase the connection has no radial component. In (8.21), the radial d_I pole series vanishes when the radial $\delta _I$ vanishes. The component coefficients (9.16), (9.26) explicitly imply this through two loops. In the supersymmetric local-source prescription, (7.5) supplies the formal all-orders identity. A first new d_I simple pole at three loops, if present in another continuation, would enter the Weyl-flattened source at this order as a finite $h^{3}$ term, because the local coupling perturbation at leading order carries $\epsilon$. Its first effect on the four-dimensional additive beta would be at order $h^{4}$. This argument assumes no extra evanescent operators or independent curvature-source conventions beyond the stated continuation and EOM projection.

**DERIVED** The soft mass formula of Jack–Jones–Pickering, Eqs. (6)–(8), gives $\Gamma=6h\partial_h\gamma$ for the coefficient of a single soft $|X|^{2}$ source. **DERIVED** $Z_M^{-}¹=1-B/(2\epsilon h)$.

## Runnable check

**DERIVED** Extract and run with Python 3 and SymPy.

```python
import sympy as s
h, e, k, L = s.symbols("h eps k L")
a, vx, vy, z, K = s.symbols("a vx vy z K")
B = 3*h**2 - 3*h**3 + k*h**4
H = B - 2*e*h
Gamma = h*s.diff(B/h, h)
Zinv = 1 - B/(2*e*h)
assert s.expand(H*s.diff(Zinv,h) - Gamma*Zinv) == 0
f = B/(6*h)
assert s.expand(B*s.diff(f,h) - Gamma*f) == 0
Z = 1+3*h/(2*e)+h**2*(9/(4*e**2)-3/(2*e))
ad = e/(3-2*e)
aC = a - ad + B/(2*h*(3-2*e))
assert s.simplify(s.series(ad+Z*aC-Z*a,h,0,3).removeO()) == 0
for j in (0,1):
    assert sum(m**j*w for m,w in zip((1,2,4),(2,-3,1))) == 0
assert s.simplify(sum(m*(s.log(m)-1) for m in (1,2,4))
                  - (10*s.log(2)-7)) == 0
P0 = (vx**2+vy**2)/(432*K*z)
run = 3*h*vx*s.diff(P0,vx)+h*z*s.diff(P0,z)
assert s.simplify((run-2*h*P0).subs(vy,-vx)) == 0
ct_residue = s.Rational(3,2) - s.Rational(1,2)
assert ct_residue == 1
assert s.limit((s.exp(-e*L)-s.exp(-2*e*L))/e,e,0) == L
assert s.simplify(sum(w*w*s.log(m)/m for w,m in zip((2,-3,1),(1,2,4)))
                  - 5*s.log(2)) == 0
print("FFZ evanescent conversion, Newton sums and slope logarithm passed")
```
